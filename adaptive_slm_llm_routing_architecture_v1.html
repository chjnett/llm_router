Targeted Distillation

Random KD Baseline

Resolvable failure 집합에서 동일한 개수 N을 무작위로 샘플링하여 LoRA.

Cluster-balanced KD

K-means 후 각 cluster에서 균등하게 샘플링하여 다양한 failure mode를 포함.

F_KD = { x | Lower(x)=Wrong ∧ Upper(x)=Correct } N_random = N_cluster 예시: K = 8 cluster당 50개 총 N = 400
Upper가 틀린 example은 teacher target으로 사용하지 않는다. 실제 gold scorer로 정답임이 확인된 Upper response만 LoRA target에 포함한다.
8

Router Adaptation

No Adaptation

Lower′로 개선됐지만 기존 router를 그대로 유지. Adaptation 필요성 검증용 baseline.

LR Retraining

R_train을 Lower′로 재평가한 새 routing label을 사용해 LR을 처음부터 다시 학습.

kNN Pool Rebuild

기존 embedding은 재사용하고, Lower′ 재평가 결과에 따라 expert label만 다시 구축.

Before: Lower⁽⁰⁾ → y⁽⁰⁾(x) After KD: Lower⁽¹⁾ → y⁽¹⁾(x) Possible: y⁽⁰⁾(x) ≠ y⁽¹⁾(x)

평가 지표

Task Accuracy

최종 시스템 응답 정확도.

Lower Accuracy

Distillation 전후 Lower 자체 성능.

Resolvable Failure Acc.

target failure 영역에서의 개선폭.

Lower Coverage

전체 query 중 Lower가 처리한 비율.

Upper Call Rate

비싼 Upper 모델 호출 비율.

Unsafe Routing Rate

Lower로 보냈으나 Lower가 틀린 비율.

Normalized Cost

Always-Upper 대비 상대 계산 비용.

Routing Accuracy

routing label 예측 정확도.

Adaptation Gain

router update 전후 quality–cost 개선량.

Threshold 정책

maximize Lower Coverage(τ) subject to Quality(τ) ≥ 0.95 × Quality(Always Upper)

최종 논문에는 단일 τ 결과뿐 아니라 quality–cost curve도 함께 제시한다.

연구 가설

H1

Frozen query embedding을 사용하는 단순 kNN retrieval router는 parametric LR router와 경쟁 가능한 quality–cost routing 성능을 보이는가?

H2

Cluster-balanced targeted distillation은 동일 데이터 예산의 random distillation보다 SLM의 resolvable failure를 효과적으로 감소시키는가?

H3 · Main

SLM capability가 distillation으로 변화한 이후 router adaptation은 quality–cost trade-off를 개선하며, non-parametric pool rebuilding은 parametric retraining에 대한 경쟁력 있는 adaptation 방법인가?
