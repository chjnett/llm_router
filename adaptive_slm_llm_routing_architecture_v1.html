3. Ablation · 라우팅 전용 대조 학습

세 가지 파일럿이 Frozen BGE AUC를 넘지 못해 핵심 방법이 아니라 query-only representation의 한계를 보여주는 비교 실험으로 유지한다.

Frozen semantic embedding의 한계

같은 주제의 쉬운 문제와 어려운 문제를 가깝게 배치한다. 현재 파일럿의 LR routing AUC는 약 0.59로 분리력이 낮다.

  • 주제 유사성은 높지만 난이도는 다를 수 있음
  • kNN neighborhood가 routing label과 불일치
  • Lower가 바뀌어도 공간은 그대로 남음

Capability-aware embedding

같은 routing label은 가깝게, 의미가 유사하지만 label이 다른 hard negative는 멀게 학습한다.

  • Positive: Lower-success ↔ Lower-success
  • Positive: Upper-needed ↔ Upper-needed
  • Hard negative: 의미는 가깝지만 routing label은 반대
L_total = L_supervised-contrastive + λ · L_routing-classification
label = 1 if Lower correct; label = 0 if Lower wrong and Upper correct
both-wrong examples are excluded from representation training
설계 선택권장안이유
Encoder updateLoRA 또는 마지막 1~2 layer1,000개 pilot에서 full fine-tuning 과적합 방지
Positive sampling동일 label + 의미 neighborhood무관한 문제까지 강제로 collapse하는 현상 완화
Negative samplingFrozen BGE 기반 hard negative + random mix난이도 경계를 직접 학습하면서 전역 안정성 유지
